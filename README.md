# De Wolf’s Drone Missie Academie — 5.0 grafische verbouwing

Gebaseerd op versie 4.9. De bestaande theorie en examens zijn ongewijzigd.

### Nieuw in de vliegwereld
- WebGL-materiaalshader met procedurele baksteenvoegen op gevels, dakpanpatronen op schuine daken, gevarieerd gras, waterreflecties en asfaltkorrel.
- Zachtere hemelbelichting en warm directioneel zonlicht.
- Schaduwachtige contactvlakken onder huizen en bomen.
- Stoepbanden rondom wegen en rijkere textuurwerking op de bestaande geometrie.
- Bestaande missies, cameratoetsen, foto-opdrachten, punten, RTH en mobiele bediening behouden.

### Technische beperking
Dit zijn procedurele texturen en niet nieuwe fotogrammetrische modellen of echte realtime schaduwkaarten. Voor een natuurgetrouwe virtuele stad met originele gebouwmodellen is aanvullend 3D-modelleringswerk nodig.

### Installatie
Plaats de inhoud van deze map (index.html in de hoofdmap) op een nieuwe GitHub Pages-branch of repository. Probeer eerst op de doelapparaten.
